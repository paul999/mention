# phpBB mentions

This repository contains the `paul999/mention` phpBB extension.

- [Installation and usage](paul999/mention/README.md)
- [Extension source files](paul999/mention/)
- [License](paul999/mention/license.txt)

To install, copy `paul999/mention/` into your forum's `ext/paul999/mention/` directory. The repository-level build and CI files are for development and are not part of the phpBB extension folder.
